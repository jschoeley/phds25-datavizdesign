# DHS borders

Jonas Schöley [![ORCID](https://info.orcid.org/wp-content/uploads/2019/11/orcid_16x16.png)](https://orcid.org/0000-0002-3340-8518) · [jschoeley.com](https://www.jschoeley.com/)

Using [`sf`](https://r-spatial.github.io/sf/index.html) we identify and plot pairs of DHS regions which share an international border. This example demonstrates how to import shapefiles into R and how to perform spatial computations on vector data.
